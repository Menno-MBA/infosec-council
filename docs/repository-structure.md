# Repository structure

One repo serves all three editions. Personas, scripts and assets have a single source of truth
under `.claude/`; the desktop skill and the ChatGPT knowledge folder are both generated from
them, and CI fails the build if they drift.

```

├── LICENSE-CC-BY-SA-4.0.txt            # CC BY-SA 4.0 (council content)
├── package.json                        # npx installer metadata + the `npm test` gate

│   ├── plugin.json
│   └── marketplace.json
```

## Where the sources of truth are

| Thing | Canonical location | Generated copies |
|---|---|---|
| Persona definitions | `.claude/agents/*.md` | `chatgpt/knowledge/council-personas.md` |
| Regulatory register | `.claude/skills/infosec-council/frameworks.md` | `chatgpt/knowledge/frameworks.md` |
| House context | `.claude/skills/infosec-council/context.md` | `chatgpt/knowledge/context.md` |
| Council protocol | `.claude/skills/infosec-council/SKILL.md` | hand-maintained mirrors in `desktop/SKILL.md` and `chatgpt/INSTRUCTIONS.md` |

The first three are regenerated by `scripts/sync-chatgpt.js` and CI fails if they drift.

The protocol mirrors are **not** generated — the three editions legitimately differ, because
Desktop has no isolated sub-agents and the GPT has no persistent journal. A whole-file diff
would be red forever and nobody would read it. Instead `scripts/check-desktop-parity.js`
asserts that a named set of load-bearing rules appears in all three, and that a small set of
deliberately-excluded rules appears only where it can work.

## Nothing binary is committed

`dist/` is gitignored. The desktop and plugin ZIPs are built by CI and attached to each
release, which is what makes the one-click download link work.
